# Polices de la version initiale V2

Sur `test-ui`, les polices initiales sont rétablies : Archivo Black pour les grands titres, Poppins pour le corps et les titres secondaires du site public, Inter dans les espaces connectés. Elles sont chargées par `next/font/google` depuis `app/(site)/layout.tsx` et `app/layout.tsx`.

Les fichiers d’essai Sensa Wild Fill et Source Han Serif ont été retirés de cette branche. La variante Sensa Wild Fill reste sur `feat(UX/UI)` ; voir [`docs/TYPOGRAPHY_COMPARISON.md`](../../docs/TYPOGRAPHY_COMPARISON.md).
